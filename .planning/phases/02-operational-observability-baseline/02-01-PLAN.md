<threat_model>

## Trust Boundaries

| Boundary | Description |
| -------- | ----------- |
| client->middleware | Untrusted headers cross into correlation context generation. |
| middleware/interceptor->logs | Runtime request metadata is persisted to logs consumed by operators. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --------- | -------- | --------- | ----------- | --------------- |
| T-02-01 | Spoofing | correlation-id middleware | mitigate | Validate inbound header format; replace malformed values with server-generated UUID v4. |
| T-02-02 | Information Disclosure | metrics interceptor | mitigate | Log allowlisted fields only and never log bodies/tokens/secrets. |
| T-02-03 | Repudiation | request logging chain | mitigate | Ensure correlationId is always generated/propagated and included in structured events. |
| T-02-SC | Tampering | npm install surface | mitigate | Add only @nestjs/terminus package already approved in research. |

</threat_model>
